1 - a) Explique, com suas palavras, o que é abstração em programação orientada a objetos.

Abstração é mostrar o que importa e esconder o que não importa. Ao modelar uma entidade, mantemos só as características relevantes para o problema que o sistema resolve, e ao usar um objeto, conhecemos o que ele faz sem precisar saber como ele faz.


b) Qual a diferença entre abstração e encapsulamento?

Abstração é decisão de desing e o encapsulamento é o mecanismo que garante essa decisão no código. Enquanto a abstração responde a pergunta de como mostrar, o encapsulamento lida com como proteger.


c) Quando você usa lista.add("Ana"), você sabe como o Java guarda esse elemento na memória? Por que isso é um exemplo de abstração?

Não, Ao chamar lista.add("Ana") só sabemos o que o metodo faz: adicionar o elemento ao final da lista. É sim um exemplo claro de abstração pois List expõe uma operação simples e abstrai a complexidade/detalhes de implementação.

Explique quem pode acessar um atributo ou método declarado com cada modificador:

a) private -> Somente a pŕopria classe pode acessar, nenhuma outra enxerga, nem as filhas.
b) protected -> A propria classe, o mesmo pacote e as filhas mesmo em outros pacotes. Usado quando queremos que as filhas tenham acesso aos atributos mas sem deixar publico.
c) default -> A propria classe e qualquer outra do mesmo pacote. Fora do pacote ninguem enxerga, nem as filhas.
d) public -> Qualquer classe de qualquer pacote.
